# Master Folder – Internal Orchestration

Purpose
The `/master` folder contains **internal orchestration files** that define how PayMate AI’s agents collaborate, escalate, and log evidence.  
These files are **not investor‑facing** but are critical for contributors, auditors, and governance reviews.

Contents

- **Master-Prompt.md** → Unified directives for all agents.
- Future orchestration files (if needed) → Agent role maps, escalation hierarchies, fallback protocols.

Usage

- Contributors may reference the Master Prompt to understand agent workflows.
- Auditors may review orchestration logic for compliance and governance maturity.
- Investors should rely on **Investor-Packet.md** and **Governance-Binder.md** for polished disclosures, not raw orchestration files.

Outcome

The `/master` folder ensures PayMate AI’s orchestration framework is **transparent internally** while keeping investor communications **polished and external‑facing**.
