Board Governance Principles

1. **Cadence**
   - Board meetings scheduled in BOARD-CALENDAR.md.
   - Quarterly reviews and annual strategic sessions documented.

2. **Evidence Logging**
   - Board decisions and governance actions logged in BOARD-REGISTER.md.
   - Linked to risk, audit, and financial domains for traceability.

3. **Transparency**
   - Board packet consolidates governance evidence for oversight.
   - Annual disclosures aligned with investor confidence.

4. **Confidence**
   - Governance binder integrates board evidence across domains.
   - Continuous improvement cycles documented for board assurance.

Workflow Integration

- Board meetings → scheduled in calendar.
- Decisions and actions → logged in register.
- Evidence consolidated → board packet and governance binder.
- Oversight → linked to risk, audit, financial, and investor domains.
