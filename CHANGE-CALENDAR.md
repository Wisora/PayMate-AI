# Change Calendar – PayMate AI

Purpose
Provide a structured calendar of product and governance changes.  
Complements CHANGE-REGISTER.md by mapping changes to specific quarters and governance cycles.

Quarterly Changes

- **Q1 (January – March)**
  - Accessibility regression fix → Automated WCAG checks added to CI/CD.
  - Investor communication upgrade → COMMUNICATIONS.md formalized.
  - Governance binder consolidation → GOVERNANCE-BINDER.md introduced.

- **Q2 (April – June)**
  - Multilingual onboarding improvements → Localized contributor guides.
  - CI/CD pipeline optimization → Build time reduced with caching.
  - Investor packet creation → INVESTOR-PACKET.md bundled key documents.

- **Q3 (July – September)**
  - Investor deck alignment → BOARD-DECK.md localized and standardized.
  - Security governance → SECURITY-POLICY.md formalized disclosure and patching.
  - Accessibility guide → ACCESSIBILITY-GUIDE.md introduced for contributors.

- **Q4 (October – December)**
  - Risk visualization → RISK-MATRIX.md and RISK-HEATMAP.md added.
  - Metrics consolidation → METRICS-DASHBOARD.md created for KPIs.
  - Lessons cycle → LESSONS-CALENDAR.md and CONTINUOUS-IMPROVEMENT.md introduced.

Annual Changes

- Consolidated governance binder presented in board deck.
- Strategic roadmap updated for next year.
- Continuous improvement cycle documented in EVOLUTION.md.

Usage

- **Contributors** → Track quarterly changes for workflow alignment.
- **Governance Leads** → Ensure changes logged in CHANGE-REGISTER.md.
- **Investors** → Review calendar for confidence in structured change management.

Review Cadence

- **Quarterly** → Calendar updated with new changes.
- **Annual** → Consolidated calendar presented in board deck.
