Security Governance Principles

1. **Policies**
   - Security standards defined in SECURITY-POLICY.md.
   - Contributors required to follow policies in workflows.

2. **Evidence Logging**
   - Security incidents and remediations logged in SECURITY-REGISTER.md.
   - Linked to compliance and audit registers for traceability.

3. **Cadence**
   - Quarterly security reviews tracked in SECURITY-CALENDAR.md.
   - Annual consolidated security audit presented in board deck.

4. **Transparency**
   - Security evidence consolidated annually in governance binder.
   - Investor disclosures aligned with security cadence.

Workflow Integration

- Security policies → defined in SECURITY-POLICY.md.

- Reviews and audits → tracked in SECURITY-CALENDAR.md.
- Evidence consolidated → governance binder and board deck.
