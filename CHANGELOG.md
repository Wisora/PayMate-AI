# Changelog – PayMate AI

Purpose
Document technical release notes for each version.  
Ensure every change is traceable to governance registers and investor disclosures.

Format

Each entry must include:

- **Version** → Semantic version (e.g., v1.2.0).
- **Date** → Release date.
- **Category** → Added, Changed, Fixed, Security, Compliance.
- **Details** → Short description of change.
- **Governance Link** → Reference to CHANGE-REGISTER.md entry.
- **Investor Link** → Reference to Investor-Packet.md or Quarterly-Confidence-Summary.md.

Example Entries

- Governance link: CHANGE-REGISTER.md → CR-012.

Checklist for Each Entry

- [ ] Version number incremented.
- [ ] Date recorded.
- [ ] Categories applied (Added, Changed, Fixed, Security, Compliance).
- [ ] Governance register ID referenced.
- [ ] Investor packet or confidence summary linked.

Outcome

Provides a transparent technical release log, proving every change is traceable to governance and investor disclosures.
