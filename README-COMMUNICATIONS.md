Communications Governance Principles

1. **Transparency**
   - Communications logged in COMMUNICATIONS-REGISTER.md.
   - Quarterly updates tracked in COMMUNICATIONS-CALENDAR.md.

2. **Traceability**
   - Communications evidence linked to contributor, investor, and board calendars.
   - Consolidated annually in board deck.

3. **Confidence**
   - Communications disclosures integrated into INVESTOR-PACKET.md.
   - Contributor notices aligned with governance cadence.
