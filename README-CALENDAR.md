Calendar Governance Principles

1. **Consolidation**
   - All domain calendars linked in CALENDAR-MASTER.md.
   - Evidence logged in CALENDAR-REGISTER.md.

2. **Cadence**
   - Quarterly reviews across domains tracked in master calendar.
   - Annual consolidated governance cadence presented in board deck.

3. **Transparency**
   - Master calendar ensures all stakeholders align on cycles.
   - Investor disclosures integrated into cadence framework.

Workflow Integration

- Domain calendars → linked in master calendar.
- Reviews and updates → logged in calendar register.
- Consolidated cadence → governance binder and board deck.
