# PayMate AI UI/UX Checklist

## Visual Design

- [ ] Consistent use of Emerald-600 for primary actions.
- [ ] Slate-900 for high-contrast text and dark elements.
- [ ] Rounded-xl (12px) or Rounded-2xl (16px) for all cards and buttons.
- [ ] Subtle borders (border-slate-100) on white backgrounds.

## Interaction

- [ ] Framer Motion transitions between dashboard tabs.
- [ ] Hover states for all interactive elements.
- [ ] Loading states (spinners/skeletons) for payment processing.
- [ ] Toast notifications for success/error feedback.

## Accessibility

- [ ] Contrast ratio > 4.5:1 for all text.
- [ ] Keyboard navigation support for the calendar.
- [ ] Aria-labels for icon-only buttons.
- [ ] Support for Right-to-Left (RTL) languages.

## Mobile Responsiveness

- [ ] Sidebar collapses into a hamburger menu on mobile.
- [ ] Calendar grid scales down or switches to list view.
- [ ] Touch targets are at least 44x44px.
- [ ] Viewport meta tag configured for no-scaling.
