# PayMate AI – Governance Board Deck Style Guide

Purpose
Define visual standards for board and investor presentation decks.  
Ensures consistency, professionalism, and accessibility across all governance slides.

Color Palette

- **Primary Blue (#1E3A8A)** → Trust, governance authority
- **Secondary Teal (#0D9488)** → Transparency, compliance assurance
- **Accent Gold (#F59E0B)** → Investor confidence, highlights
- **Neutral Gray (#6B7280)** → Backgrounds, text balance
- **White (#FFFFFF)** → Clean space, accessibility

Typography

- **Headings:** Montserrat Bold, 28–32pt
- **Subheadings:** Montserrat SemiBold, 20–24pt
- **Body Text:** Open Sans Regular, 16–18pt
- **Captions/Notes:** Open Sans Italic, 14pt
- **Accessibility Rule:** Minimum contrast ratio 4.5:1

Layout Standards

- **Slide Margins:** 1 inch all sides
- **Grid System:** 2‑column layout for content + visuals
- **Header/Footer:** Consistent branding bar with logo and date
- **Icons:** Simple line icons for governance, compliance, audit, risk
- **Charts:** Use bar/line charts for metrics, pie charts for distribution

Visual Elements

- **Governance Framework Diagram** → Organizational structure visual
- **Compliance Register Snapshot** → Table excerpt with highlights
- **Audit Dashboard** → Key metrics visualized
- **Risk & Mitigation Flow** → Linked arrows showing risk → mitigation → resolution
- **Continuous Improvement Loop** → Circular diagram showing lessons → improvements → evolution

Accessibility Standards

- Alt text for all visuals
- High‑contrast text and backgrounds
- Avoid red/green combinations (color‑blind safe)
- Minimum font size 16pt for readability

Usage Notes

- Stored in `/docs/investor-presentations/binder-governance-board-deck-style-guide.md`.
- Serves as **visual design reference** for all board and investor decks.
- Complements board deck outline, executive summary, and governance assurance docs.
