# PayMate AI – Verification Guide for Cycles

Purpose
Provide a dedicated verification guide.  
Ensures cross‑checks, sign‑offs, and accuracy validation are consistently applied across quarterly, annual, and final stages.

Verification Standards

- [ ] Verification framework documented in `/docs/verification/framework.md`
- [ ] Cross‑checks performed across governance, compliance, security, quality, accessibility, audit, risk, roadmap, transparency, and contributor cycles
- [ ] Sign‑off sheets validated against master cycle index
- [ ] Verification logs maintained in `/logs/verification/`
- [ ] Independent reviewer confirmation included

Quarterly Verification Cycle

- [ ] Quarterly verification performed across all domains
- [ ] Verification findings logged in `/logs/verification/quarterly/`
- [ ] Sign‑offs confirmed + documented
- [ ] Quarterly verification report archived

Annual Verification Cycle

- [ ] Annual verification performed across all domains
- [ ] Annual verification findings compiled into master annual report
- [ ] Annual verification packet archived in `/logs/verification/annual/`
- [ ] Investor packet cross‑checked against verification outcomes

Final Verification Review

- [ ] Verification checklist confirmed in master final review
- [ ] Verification visuals included in investor packet
- [ ] Infographic summary prepared for investor materials
- [ ] Accessibility standards applied across verification reports

Continuous Verification Loop

- [ ] Quarterly verification logs synced with annual verification report
- [ ] Annual verification report synced with master annual report
- [ ] Final verification review outcomes fed into next year’s roadmap
- [ ] Lessons learned documented + integrated into contributor workflows
