# PayMate AI – Verification Guide

Purpose
Provide clear instructions on how to use the verification checklists.  
Ensures contributors and governance leads know when to apply **quarterly**, **annual**, **final**, and **visual** checklists.

Quarterly Verification

**File:** `docs/quarterly-verification.md`  
**Use:** Every 3 months  
**Scope:**

- Confirm all cycle guides are updated
- Refresh visuals and logs for the quarter
- Lightweight, fast update form

Annual Verification

**File:** `docs/annual-verification.md`  
**Use:** Once per year  
**Scope:**

- Renew compliance certifications (ISO, SOC, GDPR, etc.)
- Confirm accessibility compliance (WCAG 2.1 AA or higher)
- Align investor packet with annual outcomes
- Archive annual logs and visuals

Final Review

**File:** `docs/ai-finance-final-review.md`  
**Use:** End of year (after annual verification)  
**Scope:**

- Capture lessons learned (successes, challenges, improvements)
- Feed outcomes into next year’s roadmap
- Confirm investor packet readiness
- Archive final year outcomes

Visual Master Checklist

**File:** `docs/ai-finance-checklist-visual.md`  
**Use:** Anytime (quick reference)  
**Scope:**

- Confirm presence of all cycle guides
- Verify visuals and logs directories exist
- High‑level dashboard for repo completeness

Workflow Rhythm

- **Quarterly Verification** → short updates every 3 months
- **Annual Verification** → full compliance + investor alignment once a year
- **Final Review** → lessons learned + roadmap integration at year‑end
- **Visual Checklist** → quick reference anytime
