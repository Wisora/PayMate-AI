# PayMate AI – Governance Dashboard Style Guide

Purpose
Define the visual design standards for the governance evidence dashboard.  
Ensures consistent color, typography, and iconography across all investor‑facing visuals.

Color Palette

| Element | Color | Usage |

|----------|--------|--------|

| Compliance | #4CAF50 (Green) | Success, verified audits |
| Accessibility | #2196F3 (Blue) | Inclusivity and usability |
| Security | #9C27B0 (Purple) | Protection and integrity |
| Verification | #FF9800 (Orange) | Review and validation |
| Transparency | #F44336 (Red) | Visibility and openness |
| Background | #F5F5F5 (Light Gray) | Neutral dashboard backdrop |
| Text | #212121 (Dark Gray) | Primary text color |
| Accent | #607D8B (Slate Gray) | Secondary labels and borders |

Typography

- **Primary Font:** Segoe UI (for clarity and accessibility)
- **Secondary Font:** Roboto (for charts and data labels)
- **Font Sizes:**
  - Titles: 24 pt
  - Subtitles: 18 pt
  - Body Text: 14 pt
  - KPI Values: 28 pt bold

Iconography

- Compliance → ✅ Checkmark
- Accessibility → ♿ Wheelchair
- Security → 🛡️ Shield
- Verification → 📋 Clipboard with checkmark
- Transparency → 👁️ Eye

Icons should be monochrome when inactive and color‑accented when active.

Layout Standards

- **KPI Tiles:** 5 equal‑width boxes across top row.
- **Charts:** Two side‑by‑side panels (KPI Trends, Maturity Progress).
- **Evidence Snapshots:** Three boxes below charts.
- **Investor Summary:** Text section with bullet points at bottom.

Margins: 24 px outer, 16 px inner spacing.  
Grid: 12‑column responsive layout for desktop and tablet.

Visual Hierarchy

1. KPI Tiles (top priority)
2. Charts (trend visualization)
3. Evidence Snapshots (context)
4. Investor Summary (narrative)

Accessibility Standards

- Minimum contrast ratio: 4.5:1 for text.
- Alt‑text required for all icons and charts.
- Keyboard navigation supported for all interactive elements.

Export Guidelines

- Dashboard visuals exportable to Power BI, Tableau, or slide decks.
- Maintain color and typography consistency across exports.
- Include legend and data source footnote on all charts.
