# PayMate AI – Investor Presentation Binder Navigation Guide

Purpose
Provide investors and auditors with a simple guide for navigating the binder.  
Ensures quick access to presentation materials, governance evidence, and approvals.

How to Use the Binder

1. **Start with Front Matter**
   - Review the **Title Page** for versioning and distribution notes.
   - Read the **Executive Brief** for a one‑page narrative overview.
   - Check the **Binder Summary** for quarterly highlights.

2. **Navigate via Table of Contents**
   - Use the TOC to jump directly to presentation suite, governance evidence, visuals, or binder governance records.
   - Each section is linked to its corresponding document for easy access.

3. **Trace Evidence Chain**
   - Follow links from the deck to supporting governance docs (metrics, risk register, improvement log, certifications).
   - Use the **Binder Diagram** for a visual map of connections.

4. **Verify Governance Records**
   - Review the **Binder Checklist** to confirm completeness.
   - Check the **Binder Review Log** for reviewer comments.
   - Confirm the **Binder Approval Register** for formal sign‑offs.
   - Consult the **Binder Audit Trail** for timestamped actions.
   - Use the **Binder Master Index** for consolidated quarterly status.

Quick Access Tips

- **Investors:** Focus on the Executive Brief, Summary, and TOC for high‑level insights.
- **Auditors:** Use the Review Log, Approval Register, and Audit Trail for compliance verification.
- **Contributors:** Follow the Checklist and Master Index to ensure binder readiness.

Usage Notes

- Guide updated quarterly alongside binder.
- Stored in `/docs/investor-presentations/binder-navigation-guide.md`.
- Serves as the **orientation document** for investors and auditors.
