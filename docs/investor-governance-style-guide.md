# PayMate AI – Investor Governance Style Guide

Purpose
Define design standards for governance reports, compliance visuals, and audit summaries.  
Ensures consistency with investor presentation style while highlighting governance and regulatory outcomes.

Color Palette

- **Blue (#1E88E5):** Governance headers, ISO milestones
- **Green (#43A047):** Compliance successes (GDPR, SOC 2)
- **Orange (#FB8C00):** Verification cycles (quarterly, annual)
- **Red (#E53935):** Security findings or remediation tasks
- **Gray (#BDBDBD):** Archive references, background elements

Typography

- **Headers:** Bold, 24pt, Sans‑Serif (Segoe UI, Roboto, Helvetica)
- **Body Text:** Regular, 18pt
- **Notes/Subtext:** Italic, 14pt, gray
- **Tables/Logs:** Monospaced font for audit entries

Layout Standards

- **Format:** 16:9 widescreen for visuals, A4 portrait for reports
- **Sections:** Compliance, Security, Accessibility, Verification, Transparency
- **Balance:** 40% visuals, 60% text for governance reports
- **Icons:** Always paired with text labels (e.g., shield for security, document for compliance)

Accessibility

- Minimum contrast ratio: 4.5:1
- Alt‑text required for all visuals (e.g., “Quarterly verification cycle completed Q1 2026”)
- Avoid color‑only distinctions; pair with icons or labels

File Standards

- Save governance visuals as `.png` in `/docs/images/governance/`
- Naming convention:  
  governance-report-[year]-Q[quarter].png
  governance-report-[year]-Annual.png
- Archive older visuals in `/docs/images/governance/archive/`

Integration Notes

- Align governance visuals with investor presentation style guide
- Use consistent icons across dashboards, packets, and reports
- Ensure compliance highlights are visually distinct from investor highlights
