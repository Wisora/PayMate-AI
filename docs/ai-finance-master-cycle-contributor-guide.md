# PayMate AI – Contributor Guide for Cycles

Purpose
Provide a dedicated contributor guide.  
Ensures repo standards, onboarding, and workflow alignment are consistently applied across quarterly, annual, and final stages.

Contributor Standards

- [ ] Contributor handbook documented in `/docs/contributor/handbook.md`
- [ ] Repo standards enforced (linting, CI/CD, folder structure, .gitignore)
- [ ] Onboarding guides localized into supported languages
- [ ] Contributor workflows aligned with governance + investor cycles
- [ ] Visual repo maps maintained for onboarding + investor packets

Quarterly Contributor Cycle

- [ ] Quarterly contributor standards reviewed + updated
- [ ] Onboarding guides refreshed + archived
- [ ] Repo health metrics logged (PR velocity, issue resolution time)
- [ ] Quarterly contributor report archived in `/logs/contributor/quarterly/`

Annual Contributor Cycle

- [ ] Annual contributor handbook updated + archived
- [ ] Multilingual onboarding verified + confirmed
- [ ] Annual contributor metrics compiled (contributors added, churn rate, repo activity)
- [ ] Annual contributor packet archived in `/logs/contributor/annual/`

Final Contributor Review

- [ ] Contributor checklist confirmed in master final review
- [ ] Contributor visuals included in investor packet
- [ ] Infographic summary prepared for investor materials
- [ ] Accessibility standards applied across contributor guides

Continuous Contributor Loop

- [ ] Quarterly contributor logs synced with annual contributor report
- [ ] Annual contributor report synced with master annual report
- [ ] Final contributor review outcomes fed into next year’s roadmap
- [ ] Lessons learned documented + integrated into contributor workflows
