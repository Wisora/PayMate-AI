# PayMate AI – Investor Packet Archive Guide

Purpose
Provide structure and rules for archiving past investor packets.  
Ensures historical transparency, investor trust, and easy retrieval of older updates.

Archiving Rules

1. **Naming Convention**
   - Use year + cycle suffix:

     investor-packet-[year]-Q[quarter].md
     investor-packet-[year]-Annual.md
     investor-packet-[year]-Final.md

   - Example: `investor-packet-2026-Q1.md`

2. **Retention**
   - Keep all quarterly and annual packets for at least **five years**.
   - Archive older packets in a compressed `.zip` if space is limited.

3. **Update Frequency**
   - Archive after each **quarterly verification**.
   - Archive after each **annual verification**.
   - Archive after each **final review**.

4. **Documentation Linkage**
   - Reference archived packets in:
     - `docs/investor-roadmap-summary.md`
     - `docs/verification-readme.md`
     - `docs/ai-finance-final-review.md`

Accessibility

- Ensure archived packets remain readable and accessible.
- Include alt‑text for any embedded visuals.
- Maintain consistent formatting across versions.
