# PayMate AI – Roadmap Guide for Cycles

Purpose
Provide a dedicated roadmap guide.  
Ensures milestones, strategy alignment, and investor‑ready visuals are consistently applied across quarterly, annual, and final stages.

Roadmap Standards

- [ ] Strategic initiatives documented in `/docs/roadmap/strategy.md`
- [ ] Milestones aligned with governance + investor cycles
- [ ] Visual roadmap diagrams prepared for investor packets
- [ ] Roadmap updates logged in `/logs/roadmap/updates/`
- [ ] Contributor roadmap tasks integrated into repo workflows

Quarterly Roadmap Cycle

- [ ] Quarterly milestones reviewed + updated
- [ ] Roadmap visuals refreshed + archived
- [ ] Contributor roadmap tasks confirmed + logged
- [ ] Quarterly roadmap report archived in `/logs/roadmap/quarterly/`

Annual Roadmap Cycle

- [ ] Annual roadmap report completed + archived
- [ ] Strategic initiatives aligned with investor annual packet
- [ ] Roadmap visuals updated + localized for multilingual support
- [ ] Annual roadmap packet archived in `/logs/roadmap/annual/`

Final Roadmap Review

- [ ] Roadmap checklist confirmed in master final review
- [ ] Roadmap visuals included in investor packet
- [ ] Infographic summary prepared for investor materials
- [ ] Accessibility standards applied across roadmap visuals

Continuous Roadmap Loop

- [ ] Quarterly roadmap logs synced with annual roadmap report
- [ ] Annual roadmap report synced with master annual report
- [ ] Final roadmap review outcomes fed into next year’s roadmap
- [ ] Lessons learned documented + integrated into contributor workflows
