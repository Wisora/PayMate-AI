# PayMate AI – Contributor Visual Guide

Purpose
Provide a scaffold for contributors to understand how visuals are structured, updated, and integrated.  
Ensures consistency across investor materials and smooth collaboration.

Visual Workflow

**Step 1 – Create Visuals**

- 📄 Draft new visual scaffold in `/docs/`
- 🖼 Generate diagrams in `/assets/[category]/finance/`
- 🎨 Apply style guide (icons, colors, typography)

**Step 2 – Update Indexes**

- 📊 Add new visual to `docs/ai-finance-visual-index.md`
- 📍 Link visual in `docs/ai-finance-readme-visual-map.md`

**Step 3 – Sync Investor Materials**

- 📦 Ensure visual is referenced in quarterly package
- 🗂 Add snapshot to one‑pager + handout
- 📅 Include in annual summary if relevant

**Step 4 – Versioning & Storage**

- 🏷 Tag releases with quarter/year (e.g., `Q2-2026-security-visual`)
- 📜 Document updates in repo wiki
- 🔄 Maintain archive in `/assets/[category]/finance/`

Contributor Responsibilities

- ✅ Follow style guide for icons, colors, layouts
- ✅ Keep visuals aligned with roadmap milestones
- ✅ Ensure accessibility (alt text, high‑contrast themes)
- ✅ Update visual index + README map when adding visuals

Diagram Elements

- **Nodes** → Create → Index → Sync → Version.
- **Arrows** → Show flow of contributor tasks.
- **Color Coding** →
  - Blue → Creation
  - Orange → Indexing
  - Green → Syncing
  - Purple → Versioning
