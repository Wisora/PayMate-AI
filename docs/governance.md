# PayMate AI Compliance & Governance

## Compliance Framework

PayMate AI adheres to global standards for financial data and privacy.

### Data Retention Policy

- **Transaction Records**: Kept for 7 years (tax compliance).
- **User Profiles**: Deleted 30 days after account closure.
- **Audit Logs**: Kept for 1 year.

### Contributor Access Control

- All code changes must be reviewed via Pull Requests.
- Direct commits to `main` are locked.
- Secrets are only accessible to authorized CI/CD pipelines.
