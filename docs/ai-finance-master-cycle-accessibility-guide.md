# PayMate AI – Accessibility Guide for Cycles

Purpose
Provide a dedicated accessibility checklist.  
Ensures all visuals, captions, and reports meet WCAG 2.1 AA standards and multilingual requirements across quarterly, annual, and final stages.

Visual Accessibility

- [ ] Alt text provided for all diagrams and images
- [ ] Color contrast meets WCAG 2.1 AA standards
- [ ] Labels and captions localized into supported languages
- [ ] Screen reader compatibility confirmed for embedded visuals
- [ ] Infographic summaries include text equivalents

Document Accessibility

- [ ] Headings structured with semantic hierarchy (H1 → H2 → H3)
- [ ] Tables include header rows and descriptive captions
- [ ] Lists formatted with proper semantic tags
- [ ] Hyperlinks use descriptive text (no “click here”)
- [ ] PDF exports tagged for accessibility

Investor Packet Accessibility

- [ ] Investor visuals include alt text + captions
- [ ] Investor reports localized into multilingual formats
- [ ] Accessibility reviewer sign‑off included in investor packet
- [ ] Screen reader testing performed on final investor packet

Continuous Accessibility Loop

- [ ] Quarterly accessibility logs synced with annual accessibility report
- [ ] Annual accessibility report synced with master annual report
- [ ] Final accessibility review outcomes fed into next year’s accessibility roadmap
- [ ] Lessons learned documented + integrated into contributor workflows
