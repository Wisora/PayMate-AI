# PayMate AI – Investor Style Visual Scaffold

Purpose
Establish a consistent visual identity across all investor materials (deck, handouts, dashboard, package).  
Ensures clarity, professionalism, and brand cohesion.

Color Palette

- **Primary**: Deep Blue (#1E3A8A) → Trust, stability
- **Secondary**: Emerald Green (#10B981) → Growth, accessibility
- **Accent**: Bright Orange (#F97316) → Energy, innovation
- **Neutral**: Light Gray (#F3F4F6) → Backgrounds, readability

Typography

- **Headings**: Sans‑serif bold (e.g., Inter, Helvetica Neue)
- **Body Text**: Sans‑serif regular (e.g., Inter, Open Sans)
- **Code/Repo References**: Monospace (e.g., Consolas, Fira Code)
- **Consistency**: Match deck + dashboard fonts for investor polish

Iconography

- **Finance Icons**: Subscription, payment, fraud shield
- **Accessibility Icons**: Language globe, mobile device, voice bubble
- **Repo Icons**: Contributor, compliance shield, roadmap timeline
- **Style**: Flat, minimal, SVG format for scalability

Layout Standards

- **Deck Slides**: Clean margins, consistent header/footer, logo top‑left
- **Handouts**: Two‑column layout for summaries + visuals
- **Dashboard**: Grid layout with panels (metrics, compliance, roadmap)
- **Package**: Consistent spacing, aligned visuals, unified color scheme

Storage & Integration

- Save assets in `/assets/style-visual/`
- Formats: SVG (scalable), PNG (quick sharing)
- Embed into:
  - Deck (`docs/investor-deck-slides.md`)
  - Dashboard (`docs/investor-dashboard.md`)
  - Package (`docs/investor-package.md`)
