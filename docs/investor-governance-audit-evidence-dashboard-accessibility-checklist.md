# PayMate AI – Governance Dashboard Accessibility Checklist

Purpose
Ensure the governance dashboard meets WCAG 2.1 AA and inclusive design standards.  
Guarantees accessibility for all investors, contributors, and board members.

Visual Accessibility

- [ ] Minimum contrast ratio 4.5:1 for text and icons.
- [ ] Color not used as sole means of conveying information.
- [ ] KPI tiles include text labels and icons.
- [ ] Charts include legends and labeled axes.
- [ ] Dashboard supports zoom up to 200% without loss of content.

Keyboard Navigation

- [ ] All interactive elements reachable via Tab key.
- [ ] Focus indicators visible and consistent.
- [ ] No keyboard traps present.
- [ ] Skip‑to‑content link available.

Screen Reader Compatibility

- [ ] Alt‑text provided for all icons and charts.
- [ ] ARIA labels used for KPI tiles and buttons.
- [ ] Headings structured hierarchically (H1 → H2 → H3).
- [ ] Dynamic content announced properly (e.g., KPI updates).

Motion & Animation

- [ ] No flashing or blinking elements.
- [ ] Animations limited to subtle transitions under 3 seconds.
- [ ] Motion effects disabled when “Reduce Motion” setting enabled.

Language & Readability

- [ ] Plain language used for all labels and tooltips.
- [ ] Acronyms defined in glossary.
- [ ] Font size ≥ 14 pt for body text.
- [ ] Line spacing ≥ 1.5 × font size.

Testing & Validation

- [ ] Tested with accessibility tools (axe, Lighthouse, NVDA, VoiceOver).
- [ ] Accessibility audit logged in `/docs/investor-governance-audit-evidence-audit-log.md`.
- [ ] Issues tracked in governance roadmap for remediation.
