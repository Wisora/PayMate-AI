# PayMate AI – Investor Presentation Style Guide

Purpose
Provide design standards for investor presentation decks.  
Ensures all slides are consistent, professional, and investor‑ready.

Color Palette

- **Primary Blue (#1E88E5)** → Titles, headers, governance visuals
- **Green (#43A047)** → Innovation highlights
- **Yellow (#FDD835)** → Investor updates, financial metrics
- **Orange (#FB8C00)** → Compliance milestones
- **Red (#E53935)** → Security & audit outcomes
- **Purple (#8E24AA)** → Expansion projects
- **Teal (#00897B)** → Market launches
- **Gray (#BDBDBD)** → Backgrounds, placeholders

Typography

- **Title Slides:** Bold, 32pt, Sans‑Serif (Segoe UI, Roboto, or Helvetica)
- **Section Headers:** Bold, 24pt
- **Body Text:** Regular, 18pt
- **Notes / Subtext:** Italic, 14pt, gray

Layout Standards

- **Slide Ratio:** 16:9 widescreen
- **Margins:** 1 inch minimum on all sides
- **Content Balance:** 50% visuals, 50% text per slide
- **Icons:** Always paired with text labels for clarity
- **Roadmap Visuals:** Use `/docs/images/roadmap-diagram.png` and `/docs/images/roadmap-legend.png`

Accessibility

- Minimum contrast ratio: 4.5:1 for text vs background
- Alt‑text required for all visuals (e.g., “Roadmap diagram showing milestones Q1–Q4”)
- Avoid color‑only distinctions; pair with icons or labels

Slide Types

1. **Title Slide** → Logo, vision statement, date
2. **Roadmap Overview** → Diagram + legend
3. **Investor Highlights** → Top 3–5 achievements
4. **Verification Outcomes** → Compliance + audit results
5. **Lessons Learned** → Successes, challenges, opportunities
6. **Financial Highlights** → Metrics + charts
7. **Archive & Transparency** → Historical visuals reference
8. **Closing & Q&A** → Next steps + contact info

File Standards

- Save decks as `.pptx` in `/docs/investor-presentations/`
- Naming convention:  
  investor-presentation-[year]-Q[quarter].pptx
  investor-presentation-[year]-Annual.pptx
- Archive older decks in `/docs/investor-presentations/archive/`
