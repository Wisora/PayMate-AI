# PayMate AI – Master Contributor Checklist

Purpose
Provide a consolidated contributor checklist.  
Ensures repo guides, onboarding materials, and contributor standards are aligned annually before investor reviews.

Repo Guides

- [ ] README visual map updated
- [ ] Repo architecture visual synced with master index
- [ ] Contributor visual guide refreshed
- [ ] Style guide visual aligned with accessibility standards

Onboarding Materials

- [ ] Onboarding handbook updated with latest workflows
- [ ] Update checklist visual confirmed for contributors
- [ ] Visual index refreshed with new categories + reports
- [ ] Multilingual onboarding materials verified

Contributor Standards

- [ ] Coding standards documented in contributor guide
- [ ] Accessibility standards applied (alt text, captions, screen reader compatibility)
- [ ] Compliance standards confirmed (security, privacy, regulatory)
- [ ] Governance oversight confirmed for contributor workflows

Transparency Layer

- [ ] Contributor guides stored in `/docs/contributor/`
- [ ] Visual scaffolds archived in `/assets/contributor/`
- [ ] Infographic summaries included in contributor packets
- [ ] Accessibility standards applied across all contributor materials
