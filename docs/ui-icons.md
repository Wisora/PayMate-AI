# PayMate AI UI Icons

## Icon Library

We use `lucide-react` for all icons.

## Recommended Usage

- **Dashboard**: `LayoutDashboard`
- **Payments**: `CreditCard`
- **Recurring Schedule**: `RefreshCw`
- **Calendar**: `Calendar`
- **Notifications**: `Bell`
- **AI Assistant**: `Bot` or `MessageSquare`
- **Settings**: `Settings`
- **Security**: `ShieldCheck` or `Lock`
- **Global/Language**: `Globe`

## Styling

- **Size**: Default to `w-5 h-5` for menu items, `w-4 h-4` for inline text.
- **Color**: Use `text-slate-500` for inactive states, `text-emerald-600` for active/primary accents.
- **Stroke**: Use `stroke-width={2}` for a clean, professional look.
