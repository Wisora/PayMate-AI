# PayMate AI – Investor Governance README

Purpose
Provide contributors with a clear orientation guide for the governance suite.  
Explains how to navigate dashboards, checklists, compliance docs, and archives.

What’s Inside

The governance suite includes:

- **Dashboards** → Current compliance status at a glance
- **Checklists** → Step‑by‑step routines for quarterly updates
- **History Logs** → Records of past governance outcomes
- **Visuals & Style Guides** → Infographics and design standards
- **Compliance Docs** → ISO, GDPR, SOC 2, accessibility policies
- **Master Indexes** → Unified directories for quick navigation

Key Files

- `/docs/investor-governance-dashboard.md` → Current governance dashboard
- `/docs/investor-governance-dashboard-history.md` → Past dashboards log
- `/docs/investor-governance-dashboard-master.md` → Unified dashboard hub
- `/docs/investor-governance-checklist.md` → Compliance checklist
- `/docs/investor-governance-update-checklist.md` → Contributor update routine
- `/docs/investor-governance-history.md` → Governance outcomes log
- `/docs/investor-governance-style-guide.md` → Visual design standards
- `/docs/investor-governance-visual-archive-index.md` → Archived governance visuals
- `/docs/investor-governance-master.md` → Governance hub
- `/docs/investor-governance-master-index.md` → Governance directory

How to Use

1. **Start with the Dashboard** → Check `/docs/investor-governance-dashboard.md` for current compliance status.
2. **Follow the Update Checklist** → Use `/docs/investor-governance-update-checklist.md` each quarter.
3. **Log Outcomes** → Record results in `/docs/investor-governance-history.md` and dashboard history.
4. **Update Visuals** → Generate new infographics per `/docs/investor-governance-style-guide.md`.
5. **Archive Properly** → Store visuals in `/docs/images/governance/archive/` and update archive index.
6. **Verify Compliance** → Confirm ISO, GDPR, SOC 2, accessibility in `/docs/compliance.md`.
7. **Sync Master Files** → Ensure `/docs/investor-governance-master.md` and `/docs/investor-governance-master-index.md` are current.

Contributor Notes

- Always update governance docs **in sync with investor dashboards**.
- Accessibility compliance is mandatory (contrast, alt‑text, labels).
- Archives must be maintained for transparency.
- Sign‑offs required from Governance Lead, Compliance Officer, Investor Relations, Finance.
