# PayMate AI – Investor Assets Checklist

Overview
This file lists all visuals required for the investor deck, dashboard, and repo documentation.  
Assets can be created by contributors/designers and stored in `/assets/` for easy reuse.

Branding

- Logo (vector + PNG)
- Color palette swatches (Deep Blue, Emerald Green, Gold, Gray, Charcoal)
- Typography samples (Montserrat/Open Sans for headings, Lato/Roboto for body)

Product Demo

- Screenshots of demo routes:
  - Health check
  - Login
  - Dashboard
  - Subscriptions
  - Fraud alerts
- Workflow diagram (ASCII → vector graphic)

Roadmap

- Timeline graphic (MVP → Beta → Production → Enterprise)
- Milestone icons (checkmarks, rockets, servers)

Compliance

- Data flow diagram:
  - User → API → Secure Storage → Audit Logs → Compliance checks
- Certification badges (GDPR, CCPA, POPIA, SOC 2, ISO 27001)

Scaling

- Architecture diagram:
  - Free hosting MVP
  - Paid tier migration
  - Enterprise Kubernetes
- CDN + cloud icons

Market Opportunity

- Bar chart: subscription economy growth
- Pie chart: multilingual accessibility gap
- Infographic: personal finance assistant demand

Business Model

- Revenue model graphic (freemium → paid tiers → B2B integrations)
- Conversion funnel diagram (free → paid → enterprise)

Team

- Founder headshot (Craig)
- Contributor icons (open‑source community)
- Team structure diagram

Ask

- Funding graphic (stacked bar or pie chart)
- Partnership icons (fintech logos, handshake icon)

Dashboard

- Line chart: Monthly Active Users (MAU)
- Bar chart: New signups
- Gauge: Retention rate
- Pie chart: Multilingual usage
- Line chart: Fraud alerts delivered
- Progress bar: SOC 2 readiness
- Line chart: MRR (Monthly Recurring Revenue)
- Bar chart: Contributor growth

Storage & Organization

- Store all assets in `/assets/` folder
- Use consistent naming convention:
  - `logo.png`
  - `roadmap-timeline.png`
  - `compliance-diagram.png`
  - `scaling-architecture.png`
  - `market-bar-chart.png`
  - `business-model.png`
  - `team-headshot.png`
  - `dashboard-mau.png`

Next Steps

- Assign contributors/designers to create each asset
- Review against style guide (`docs/style-guide.md`)
- Update deck (`docs/investor-deck-slides.md`) with final visuals
