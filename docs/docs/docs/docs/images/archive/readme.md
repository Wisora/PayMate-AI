# PayMate AI – Roadmap Archive Guide

Purpose
Provide a clear structure for archiving older roadmap diagrams and visuals.  
Ensures historical tracking of milestones, design evolution, and investor transparency.

Archiving Rules

1. **Version Naming**
   - Use year or version suffixes:

     roadmap-diagram-[year].png
     roadmap-diagram-[version].png
     roadmap-legend-[version].png

   - Example: `roadmap-diagram-2026-v2.png`

2. **Retention**
   - Keep at least the last **three years** of roadmap visuals.
   - Archive older versions in a compressed `.zip` file if space is limited.

3. **Update Frequency**
   - Archive visuals after each **annual verification** or **final review**.
   - Add a short note in the commit message describing the update.

4. **Accessibility**
   - Ensure archived visuals remain readable and accessible.
   - Include alt‑text in documentation for each archived image.
