# PayMate AI – Master Contributor Cycle Checklist

Purpose
Provide a consolidated contributor cycle checklist.  
Ensures onboarding guides, repo standards, and contributor materials flow smoothly across quarterly, annual, and final stages before investor reviews.

Quarterly Contributor Cycle

- [ ] Contributor visual guides refreshed + archived in `/docs/contributor/quarterly/`
- [ ] Repo architecture visual updated + synced with master index
- [ ] Coding standards reviewed + updated in contributor guide
- [ ] Accessibility standards confirmed (alt text, captions, screen reader compatibility)
- [ ] Quarterly contributor log archived

Annual Contributor Cycle

- [ ] Contributor annual report visual completed
- [ ] Onboarding handbook updated with latest workflows
- [ ] Multilingual onboarding materials verified
- [ ] Annual contributor highlights synced with investor annual report
- [ ] Annual contributor packet archived in `/docs/contributor/annual/`

Final Contributor Review

- [ ] Contributor checklist confirmed in master final review
- [ ] Contributor visuals included in investor packet
- [ ] Infographic summary prepared for investor materials
- [ ] Accessibility standards applied across all contributor documents

Continuous Contributor Loop

- [ ] Quarterly contributor logs synced with annual contributor report
- [ ] Annual contributor report synced with master annual report
- [ ] Final contributor review outcomes fed into next year’s contributor roadmap
- [ ] Lessons learned documented + integrated into repo workflows
