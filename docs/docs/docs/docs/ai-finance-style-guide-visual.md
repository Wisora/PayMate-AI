# PayMate AI – Visual Style Guide

Purpose
Provide a scaffold for a style guide infographic.  
Ensures icons, colors, and layouts are standardized across all investor visuals.

Iconography

- 📊 KPIs → bar/line charts
- 🛡 Security → shield icon
- 📜 Governance → scroll icon
- 🚀 Roadmap → rocket icon
- 🌍 Accessibility/Multilingual → globe icon

Color Palette

- Blue → KPIs & Metrics
- Orange → Roadmap & Milestones
- Green → Compliance & Security
- Purple → Accessibility & Inclusivity
- Grey → Investor Materials

Typography

- **Headings** → Sans‑serif bold (consistent size hierarchy)
- **Body Text** → Sans‑serif regular, high readability
- **Highlights** → Color‑coded emphasis (no italics for accessibility)

Layout Standards

- **Sections** → Header → Content → Footer
- **Diagrams** → Nodes + arrows, color‑coded categories
- **Infographics** → Max 3–4 sections per visual for clarity
- **Accessibility** → High‑contrast theme option, alt text for all visuals

Storage & Versioning

- Store style guide visuals in `/assets/style/finance/`.
- Tag releases with version (e.g., `v1.0-style-guide-visual`).
- Document updates in repo wiki.
