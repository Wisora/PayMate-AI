# PayMate AI – Investor Visual Workflow

Purpose
Define the workflow for creating, updating, and integrating investor visuals.  
Ensures contributors understand how data → scaffolds → assets → materials flow together.

Workflow Diagram (Conceptual)
Data → Scaffolds → Assets → Integration → Investor Materials

1. Data Sources
   - Metrics (`docs/investor-metrics.md`)
   - Roadmap (`docs/roadmap.md`)
   - Compliance (`docs/investor-compliance-summary.md`)

2. Visual Scaffolds
   - Style → `docs/investor-style-visual.md`
   - Metrics → `docs/investor-metrics-visual.md`
   - Dashboard → `docs/investor-dashboard-visual.md`
   - Package → `docs/investor-package-visual.md`
   - Handout → `docs/investor-handout-visual.md`
   - Summary → `docs/investor-summary-visual.md`
   - One‑Pager → `docs/investor-onepager-visual.md`

3. Asset Creation
   - Charts, infographics, icons, timelines
   - Saved in `/assets/[visual-type]/` subfolders

4. Integration
   - Deck (`docs/investor-deck-slides.md`)
   - Handout (`docs/investor-handout.md`)
   - One‑Pager (`docs/investor-onepager.md`)
   - Summary Slide (`docs/investor-summary-slide.md`)
   - Dashboard (`docs/investor-dashboard.md`)
   - Package (`docs/investor-package.md`)

5. Investor Materials
   - Polished deck, handouts, dashboard, package
   - Consistent visuals across all outputs

Step Guide

- **Step 1**: Update data sources (metrics, roadmap, compliance).
- **Step 2**: Refresh scaffolds with new data.
- **Step 3**: Generate visuals (charts, infographics, timelines).
- **Step 4**: Save assets in correct `/assets/` directories.
- **Step 5**: Embed visuals into investor materials.
- **Step 6**: Review consistency with style guide.
- **Step 7**: Commit updates + tag quarterly release.

Contributor Notes

- Always follow style standards (`docs/investor-style-visual.md`).
- Use SVG for scalability, PNG for quick sharing.
- Sync visuals across all investor materials.
- Update quarterly alongside metrics + roadmap.
