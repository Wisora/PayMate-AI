# PayMate AI – Investor Presentation Style Guide

Purpose
Define visual standards for investor presentation decks.  
Ensures consistency, professionalism, and brand alignment across all quarterly presentations.

Color Palette

- **Primary Blue (#1E3A8A):** Trust, stability, governance.
- **Secondary Green (#10B981):** Growth, compliance, accessibility.
- **Accent Gold (#F59E0B):** Investor highlights, key metrics.
- **Neutral Gray (#6B7280):** Backgrounds, secondary text.
- **White (#FFFFFF):** Clean space, accessibility contrast.

Typography

- **Headings:** Montserrat Bold, 28–32pt.
- **Subheadings:** Montserrat SemiBold, 20–24pt.
- **Body Text:** Open Sans Regular, 16–18pt.
- **Captions/Notes:** Open Sans Italic, 12–14pt.

Layout Standards

- **Slide Ratio:** 16:9 widescreen.
- **Margins:** 1 inch safe zone on all sides.
- **Header/Footer:** Consistent logo placement (top left), slide number (bottom right).
- **Visual Balance:** No more than 40% text per slide; use visuals, charts, and icons.

Visual Elements

- **Charts:** Use consistent color coding (Blue = Governance, Green = Compliance, Gold = Investor).
- **Icons:** Simple line icons, consistent stroke width.
- **Images:** High‑contrast, accessibility‑friendly visuals.
- **Diagrams:** Mermaid or vector diagrams exported with consistent palette.

Accessibility Standards

- Minimum contrast ratio: 4.5:1 for text.
- Alt text required for all images.
- Avoid red/green combinations without labels.
- Font size ≥ 16pt for readability.

Usage Notes

- Style guide applied to all investor decks.
- Stored in `/docs/investor-presentations/style-guide.md`.
- Reviewed annually for updates.
- Serves as audit evidence of consistent investor communication.
