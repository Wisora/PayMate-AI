# PayMate AI – Investor Summary Visual Scaffold

Purpose
Provide a visual framework for the one‑page investor summary slide.  
Ensures key highlights are presented clearly, visually, and consistently with deck + handout.

Layout Overview

- **Header** → Logo + tagline (“Accessible Finance for the Subscription Economy”)
- **Left Column** → Problem + Solution infographic (side‑by‑side icons)
- **Right Column** → Roadmap timeline graphic (MVP → Beta → Production → Enterprise)
- **Bottom Bar** → Quick facts strip (users, compliance, funding ask)

Visual Elements

- **Problem Icon** → Subscription chaos (stacked bills, alerts)
- **Solution Icon** → PayMate AI dashboard snapshot
- **Roadmap Timeline** → Horizontal bar with milestones + dates
- **Quick Facts Strip** → Infographic style numbers (e.g., “Q2 2026 MVP”, “GDPR/CCPA compliant”, “Funding Ask: Infrastructure + Compliance”)

Style Standards

- Colors → From `docs/investor-style-visual.md` (deep blue, emerald green, bright orange, light gray)
- Typography → Deck fonts (Inter / Open Sans)
- Icons → Flat, minimal SVG (finance, compliance, accessibility)
- Layout → Balanced whitespace, clear hierarchy, single‑page impact

Asset Storage

- Directory: `/assets/summary-visual/`
- Subfolders:
  - `/problem-solution/` → Infographics
  - `/roadmap/` → Timeline graphics
  - `/quickfacts/` → Fact strip visuals

Integration

- Embed visuals into:
  - Investor Summary Slide (`docs/investor-summary-slide.md`)
  - Investor Deck (`docs/investor-deck-slides.md`)
  - Investor Package (`docs/investor-package.md`)
