# PayMate AI – Investor Governance Onboarding Guide

Purpose
Provide new contributors with a quickstart checklist for their first week.  
Helps them get familiar with governance documentation and workflows without overwhelming detail.

Day 1 – Orientation

- [ ] Read `/docs/investor-governance-readme.md` for overview
- [ ] Explore `/docs/investor-governance-master-index.md` to locate files
- [ ] Meet Governance Lead for role assignment

Day 2 – Compliance Basics

- [ ] Review `/docs/compliance.md` (ISO, GDPR, SOC 2)
- [ ] Understand accessibility standards in `/docs/investor-governance-style-guide.md`
- [ ] Shadow Compliance Officer during a mock update

Day 3 – Dashboards

- [ ] Open `/docs/investor-governance-dashboard.md` (current status)
- [ ] Explore `/docs/investor-governance-dashboard-history.md` (past logs)
- [ ] Observe how updates are logged each quarter

Day 4 – Visuals & Archives

- [ ] Review `/docs/investor-governance-visual-archive-index.md`
- [ ] Learn naming conventions for governance visuals
- [ ] Practice creating a placeholder filename (e.g., `governance-report-2026-Q2.png`)

Day 5 – Checklists & Verification

- [ ] Walk through `/docs/investor-governance-update-checklist.md`
- [ ] Observe quarterly verification in `/docs/quarterly-verification.md`
- [ ] Shadow Governance Lead during checklist completion

End of Week – Sign‑Off

- [ ] Complete onboarding exercises
- [ ] Meet with Governance Lead for review
- [ ] Gain approval to begin contributing to live governance suite

Usage Notes

- This onboarding guide is a **quickstart**, not a full training module.
- New hires should complete this before starting the full training module (`/docs/investor-governance-training.md`).
- Sign‑offs required before contributing live updates.
