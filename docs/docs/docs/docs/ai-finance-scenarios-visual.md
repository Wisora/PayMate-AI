# PayMate AI – Scenario Forecasts Visual

Purpose
Provide a scaffold for designing a scenario forecast infographic.  
Shows best case, baseline, and worst case projections for KPIs to highlight resilience and upside.

Scenario Layout (Conceptual)

**Header – Forecast Overview**

- 📅 Quarter / Year (e.g., Q3 2026)
- 🚀 Tagline: “Scenario Forecasts – Best, Baseline, Worst”

**Section 1 – KPI Projections**

- 📊 Payment Success Rate
  - Best Case → 99%
  - Baseline → 98%
  - Worst Case → 95%

- 🛡 Fraud Detection Accuracy
  - Best Case → 97%
  - Baseline → 95%
  - Worst Case → 92%

- 💰 Forecast Accuracy
  - Best Case → < 3% variance
  - Baseline → < 5% variance
  - Worst Case → < 8% variance

- 💸 Transaction Cost Savings
  - Best Case → 25% reduction
  - Baseline → 20% reduction
  - Worst Case → 15% reduction

**Section 2 – Roadmap Impact**

- 🚀 Best Case → Portal launch ahead of schedule
- 📈 Baseline → Portal launch on schedule
- ⏱ Worst Case → Portal launch delayed by 1 quarter

**Section 3 – Compliance & Accessibility**

- ✅ Best Case → ISO 27001 achieved early
- 📜 Baseline → ISO 27001 achieved on schedule
- 🔒 Worst Case → ISO 27001 delayed

Diagram Elements

- **Icons** → KPI gauges + roadmap milestones.
- **Color Coding** →
  - Green → Best Case
  - Blue → Baseline
  - Red → Worst Case

Storage & Versioning

- Store scenario visuals in `/assets/scenarios/finance/`.
- Tag releases with quarter (e.g., `Q3-2026-scenarios-visual`).
- Document updates in repo wiki.
