# PayMate AI – Investor Governance RACI Matrix

Purpose
Define role involvement in governance tasks using RACI (Responsible, Accountable, Consulted, Informed).  
Ensures clarity and avoids overlap or gaps in governance responsibilities.

Roles

- **Governance Lead (GL)**
- **Compliance Officer (CO)**
- **Investor Relations Lead (IRL)**
- **Finance Lead (FL)**

Governance Tasks

| Task                               | GL  | CO  | IRL | FL  |
| ---------------------------------- | --- | --- | --- | --- |
| Update Governance Dashboard        | R/A | C   | I   | I   |
| Maintain Dashboard History         | R/A | C   | I   | I   |
| Generate Governance Visuals        | R   | C   | C   | I   |
| Archive Governance Visuals         | R/A | C   | I   | I   |
| Maintain Compliance Docs           | I   | R/A | C   | C   |
| Verify ISO/GDPR/SOC 2              | I   | R/A | I   | C   |
| Accessibility Compliance Check     | R   | R   | C   | I   |
| Quarterly Verification Cycle       | R/A | R   | C   | C   |
| Annual Verification Cycle          | R/A | R   | C   | C   |
| Investor Packet Governance Section | I   | C   | R/A | C   |
| Finance Audit Governance Section   | I   | C   | C   | R/A |
| Lessons Learned Documentation      | R/A | C   | C   | C   |
| Final Governance Review            | R/A | R   | C   | R   |

Key

- **R (Responsible):** Does the work
- **A (Accountable):** Owns the outcome, final sign‑off
- **C (Consulted):** Provides input, expertise
- **I (Informed):** Kept updated on progress

Usage Notes

- Each governance cycle (quarterly, annual) must follow this RACI matrix.
- Accountability (A) cannot be delegated; Responsible (R) can be shared.
- Consulted (C) roles must provide timely input before sign‑off.
- Informed (I) roles receive updates but do not act directly.
