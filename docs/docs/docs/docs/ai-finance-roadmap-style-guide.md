# PayMate AI – Roadmap Style Guide

Purpose
Provide design standards for roadmap diagrams.  
Ensures all contributors create visuals that are consistent, accessible, and investor‑ready.

Color Palette

- **Primary Blue (#1E88E5)** → Governance & Risk
- **Green (#43A047)** → Innovation Pipeline
- **Yellow (#FDD835)** → Investor Updates
- **Orange (#FB8C00)** → Compliance milestones
- **Red (#E53935)** → Security & Audit milestones
- **Purple (#8E24AA)** → Expansion projects
- **Teal (#00897B)** → Market launches
- **Gray (#BDBDBD)** → Background / placeholders

Icons

- **Flag / Mountain Peak** → Vision milestones
- **Lightbulb** → Key initiatives
- **Bar chart with arrow** → Growth targets
- **Shield** → Security milestones
- **Checklist** → Compliance milestones
- **Globe** → Market expansion
- **Target** → Final success milestone

Typography

- **Title:** Bold, 24pt, Sans‑Serif (e.g., Segoe UI, Roboto)
- **Quarter Labels (Q1, Q2, Q3, Q4):** Bold, 18pt
- **Milestone Boxes:** Regular, 14pt, white text on colored background
- **Notes / Subtext:** Italic, 12pt, gray

Layout Standards

- **Timeline:** Horizontal, segmented by quarters (Q1–Q4) across multiple years
- **Milestone Boxes:** Color‑coded by category, aligned under each quarter
- **Arrows:** Show progression between milestones
- **Bottom Bars:**
  - Dark Blue → Governance & Risk
  - Green → Innovation Pipeline
  - Yellow → Investor Updates

Accessibility

- Minimum contrast ratio: 4.5:1 for text vs background
- Use alt‑text for all roadmap images (e.g., “Roadmap diagram showing milestones Q1–Q4”)
- Ensure icons are paired with text labels for clarity

File Standards

- Save roadmap visuals as `.png` in `/docs/images/`
- File name convention:  
  roadmap-diagram.png
  roadmap-diagram-[year].png
  roadmap-diagram-[version].png
- Archive older versions in `/docs/images/archive/`
