# PayMate AI – Governance Dashboard Contributor Handbook

Purpose
Provide contributors with a quick‑reference guide for daily dashboard operations.  
Summarizes essential workflows, responsibilities, and best practices.

Daily Responsibilities

- Submit evidence items using approved templates.
- Update KPI values when new data is available.
- Verify accuracy before committing changes.
- Follow accessibility and performance standards.
- Log issues in the risk register.

Key Workflows

Evidence Submission

- Use `/evidence/` directory structure.
- Include Evidence ID, Control ID, and KPI linkage.
- Submit items for Governance Lead review.

KPI Updates

- Refresh KPI tiles from metrics file.
- Confirm values match quarterly summary.
- Notify Governance Lead of anomalies.

Accessibility

- Run quick checks with axe or Lighthouse.
- Ensure alt‑text and ARIA labels are present.
- Verify keyboard navigation works.

Investor Packet Alignment

- Export visuals for quarterly summary.
- Confirm packet alignment with Investor Relations Lead.

Best Practices

- Keep evidence complete, accurate, and timely.
- Communicate issues immediately.
- Respect sign‑off workflow before release.
- Maintain transparency in all updates.
