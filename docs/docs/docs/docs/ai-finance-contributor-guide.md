# PayMate AI – Finance Contributor Guide

Purpose
Provide contributors with a practical guide for navigating and applying PayMate AI’s finance documentation.  
Ensures workflows are consistent, compliant, and aligned with investor expectations.

Core Workflow

1. **Start with Index** → `docs/ai-finance-index.md`
   - Use as the central navigation hub.

2. **Review Summary** → `docs/ai-finance-summary.md`
   - Understand the big picture before diving into details.

3. **Check Roadmap** → `docs/ai-finance-roadmap.md` + `docs/ai-finance-roadmap-visual.md`
   - Align contributions with quarterly milestones.

4. **Follow Update Checklist** → `docs/ai-finance-update-checklist.md` + `docs/ai-finance-checklist-visual.md`
   - Ensure quarterly updates are complete and consistent.

Compliance & Oversight

- **Compliance Guide** → `docs/ai-finance-compliance.md`
- **Governance Log** → `docs/ai-finance-governance-log.md`
- **Security Log** → `docs/ai-finance-security-log.md`
- **Audit Trail** → `docs/ai-finance-audit.md`
- **Quality Log** → `docs/ai-finance-quality-log.md`

👉 Contributors must log approvals, incidents, and QA checks each quarter.

Investor Materials

- **Metrics** → `docs/ai-finance-metrics.md`
- **Dashboard** → `docs/ai-finance-dashboard.md`
- **Handout** → `docs/ai-finance-handout.md`
- **One‑Pager** → `docs/ai-finance-onepager.md`
- **Package Guide** → `docs/ai-finance-package.md`
- **Investor Q&A** → `docs/ai-finance-investor-qa.md`

👉 Contributors should sync updates across metrics, dashboards, and investor handouts.

Accessibility Standards

- **Accessibility Guide** → `docs/ai-finance-accessibility.md`
- Ensure all dashboards and visuals meet WCAG AA standards.
- Provide alt text, multilingual captions, and high‑contrast themes.

Visual Navigation

- **Visual Index** → `docs/ai-finance-visual-index.md`
- **Roadmap Visual** → `docs/ai-finance-roadmap-visual.md`
- **Checklist Visual** → `docs/ai-finance-checklist-visual.md`

👉 Use visuals to quickly understand repo structure and update cycles.

Contributor Rules

- Always anonymize financial data before committing.
- Document approvals in governance logs.
- Sync roadmap milestones with quarterly updates.
- Run QA + accessibility checks before merging.
- Tag releases by quarter (e.g., `Q2-2026-finance-update`).

Next Steps

1. Familiarize yourself with the **Index + Summary**.
2. Align contributions with **Roadmap milestones**.
3. Follow the **Update Checklist** each quarter.
4. Log all QA, governance, and security actions.
5. Sync updates with investor materials + visuals.
