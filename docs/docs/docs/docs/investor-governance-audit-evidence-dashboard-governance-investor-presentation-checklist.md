# PayMate AI – Investor Presentation Checklist

Purpose
Provide a structured checklist for contributors preparing quarterly investor decks.  
Ensures slides are complete, styled, and reviewed before delivery.

Content Completion

- [ ] Title slide updated with quarter, release version, and date.
- [ ] KPI performance slide populated with metrics dashboard data.
- [ ] Trend chart updated with latest quarterly values.
- [ ] Risk & mitigation slide updated from risk register.
- [ ] Continuous improvement slide updated from improvement log.
- [ ] Roadmap & maturity model slide refreshed.
- [ ] Audit evidence & certification highlights included.
- [ ] Investor engagement slide updated with feedback log and Q&A.
- [ ] Financial & governance sign‑off slide prepared.
- [ ] Closing notes slide finalized with next meeting date.

Style & Visuals

- [ ] Colors applied per style guide (Blue, Green, Gold, Gray, White).
- [ ] Fonts applied per style guide (Montserrat + Open Sans).
- [ ] Layout adheres to 16:9 widescreen ratio.
- [ ] Logo placement consistent (top left).
- [ ] Slide numbers included (bottom right).
- [ ] Accessibility standards checked (contrast ratio ≥ 4.5:1, font size ≥ 16pt).

Review & Sign‑Off

- [ ] Governance Lead reviewed content accuracy.
- [ ] Compliance Officer verified accessibility and compliance.
- [ ] Investor Relations Lead confirmed alignment with packet.
- [ ] Finance Lead approved financial commentary.

Delivery Prep

- [ ] Deck exported to `/docs/investor-presentations/QXYYYY/`.
- [ ] PDF version generated for investor packet.
- [ ] Backup copy stored in repo.
- [ ] Investor meeting agenda cross‑checked with deck outline.
