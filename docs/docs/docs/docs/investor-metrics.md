# PayMate AI – Investor Metrics

Overview
This document outlines the key performance indicators (KPIs) PayMate AI will track and report to investors.  
Metrics are aligned with product adoption, compliance, scaling, and contributor growth.

User Growth

- Active Users (MAU/DAU) → Monthly and daily active users
- User Acquisition Rate → New signups per week/month
- Retention Rate → % of users returning after 30/60/90 days
- Churn Rate → % of users leaving per month

Engagement

- Subscriptions Tracked → Number of active subscriptions managed per user
- Fraud Alerts Delivered → Alerts successfully triggered and resolved
- Multilingual Usage → % of users engaging in non‑English languages
- Notification Response Rate → % of users interacting with alerts

Compliance & Trust

- Data Privacy Incidents → Zero tolerance target
- Audit Log Coverage\*\* → % of transactions logged
- Compliance Milestones → GDPR/CCPA/POPIA alignment, SOC 2 readiness

Scaling & Performance

- System Uptime → Target 99.9% availability
- Latency → Average response time per API call
- Performance Test Success Rate → Target 95%+ across endpoints
- Hosting Migration Milestones → Free → Paid → Enterprise

Financial Metrics

- Freemium Conversion Rate → % of free users upgrading to paid tiers
- ARPU (Average Revenue Per User) → Monthly revenue per active user
- MRR (Monthly Recurring Revenue) → Total subscription revenue
- CAC vs LTV → Customer acquisition cost vs lifetime value

Contributor Growth

- Active Contributors → Number of developers submitting PRs
- PR Acceptance Rate → % of contributions merged
- Onboarding Completion Time → Average time for new contributors to set up
- Community Engagement → Issues, discussions, and documentation updates

Reporting Cadence

- Quarterly Updates → Roadmap progress + KPI snapshots
- Annual Reports → Compliance certifications + scaling milestones
- Investor Dashboards → Real‑time metrics via GitHub Projects + analytics
