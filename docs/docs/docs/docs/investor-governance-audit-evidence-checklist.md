# PayMate AI – Investor Governance Audit Evidence Checklist

Purpose
Provide a contributor‑friendly checklist to ensure all governance audit evidence meets standards before being logged.  
Supports consistency, accuracy, and transparency across the evidence repository.

Evidence Submission Checklist

General Standards

- [ ] Evidence is complete and unaltered.
- [ ] Evidence is in approved format (PDF, CSV, PNG).
- [ ] Evidence has a unique Evidence ID assigned.
- [ ] Evidence is linked to a Control ID.
- [ ] Evidence is linked to a KPI.
- [ ] Evidence stored in correct `/evidence/` subdirectory.

Compliance Evidence

- [ ] Policy review logs captured and verified.
- [ ] Audit reports archived in compliance folder.

Accessibility Evidence

- [ ] Contributor checklists include alt‑text and contrast verification.
- [ ] Accessibility audit reports stored and signed off.

Security Evidence

- [ ] Deployment logs captured from CI/CD pipeline.
- [ ] Vulnerability scan reports archived quarterly.
- [ ] Risk register entries updated with findings.

Verification Evidence

- [ ] Reminder logs stored in verification folder.
- [ ] Contributor sign‑off records complete and accurate.
- [ ] Verification cycle completion reports included.

Transparency Evidence

- [ ] Dashboard logs synced within 7 days.
- [ ] Archive index audits completed quarterly.
- [ ] Investor packets cross‑checked and aligned.

Usage Notes

- Checklist completed before evidence is logged in register.
- Owners responsible for verifying their evidence items.
- Governance Lead reviews checklist compliance quarterly.
- Non‑compliance escalated to board via action register.
