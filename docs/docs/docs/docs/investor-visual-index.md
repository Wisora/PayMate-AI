# PayMate AI – Investor Visual Index

Purpose
Provide a central index of all visual scaffolds and asset directories.  
Ensures contributors can locate, update, and maintain visuals consistently across investor materials.

Visual Scaffolds

- **Style Identity** → `docs/investor-style-visual.md`
- **Metrics Visuals** → `docs/investor-metrics-visual.md`
- **Dashboard Visuals** → `docs/investor-dashboard-visual.md`
- **Package Visuals** → `docs/investor-package-visual.md`
- **Handout Visuals** → `docs/investor-handout-visual.md`
- **Summary Slide Visuals** → `docs/investor-summary-visual.md`
- **One‑Pager Visuals** → `docs/investor-onepager-visual.md`

Asset Directories

- `/assets/style-visual/` → Palette, typography, icon sets
- `/assets/metrics-visual/` → Charts + infographics
- `/assets/dashboard-visual/` → KPI panels + compliance charts
- `/assets/package-visual/` → Deck + handout + dashboard visuals
- `/assets/handout-visual/` → Infographics + roadmap + metrics for handout
- `/assets/summary-visual/` → Problem/solution + roadmap + quick facts strip
- `/assets/onepager-visual/` → Overview + roadmap + metrics + compliance

Integration Points

- Deck → `docs/investor-deck-slides.md`
- Handout → `docs/investor-handout.md`
- One‑Pager → `docs/investor-onepager.md`
- Summary Slide → `docs/investor-summary-slide.md`
- Dashboard → `docs/investor-dashboard.md`
- Package → `docs/investor-package.md`

Contributor Guidelines

- Always follow style standards (`docs/investor-style-visual.md`)
- Save visuals in correct `/assets/` subfolder with clear naming conventions
- Sync visuals across deck, handout, summary, dashboard, and package
- Update quarterly with new KPIs, compliance milestones, and roadmap progress
