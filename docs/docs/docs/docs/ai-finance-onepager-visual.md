# PayMate AI – Finance One‑Pager Visual

Purpose
Provide a scaffold for designing the investor one‑pager as a sleek infographic.  
Summarizes KPIs, roadmap highlights, and compliance in a single sheet.

One‑Pager Layout (Conceptual)

**Header – Brand & Tagline**

- 🚀 PayMate AI logo + tagline
- 📄 Executive Summary (1 sentence: “AI‑driven finance assistant for subscriptions, fraud alerts, and accessibility.”)

**Section 1 – KPIs Snapshot (Icons + Gauges)**

- 📊 Payment Success Rate → 98%
- 🛡 Fraud Detection Accuracy → 95%
- 💰 Forecast Accuracy → < 5% variance
- 💸 Transaction Cost Savings → 20% reduction
- ⏱ Late Fee Reduction → 80% decrease

**Section 2 – Roadmap Highlights (Timeline Strip)**

- Q2 2026 → Fraud detection live
- Q3–Q4 2026 → Predictive analytics + dashboards
- Q1–Q2 2027 → Portfolio optimization + multilingual dashboards
- Q3 2027+ → Investor portal + AI reports

**Section 3 – Compliance Badges (Icon Row)**

- ✅ PCI‑DSS
- ✅ GDPR / POPIA / CCPA
- ✅ SOC 2 (quarterly audits)
- 🔒 ISO 27001 (planned 2027)

**Section 4 – Accessibility Commitment**

- 🌍 Multilingual captions (English, Afrikaans, French, Spanish)
- 🎨 High‑contrast theme toggle
- 🖼 Alt text for charts

**Footer – Investor Callout**

- 📦 Links to package, dashboard, and investor Q&A
- 📜 Governance + audit trail references

Diagram Elements

- **Icons** → KPIs, roadmap milestones, compliance badges.
- **Color Coding** →
  - Blue → KPIs
  - Orange → Roadmap
  - Green → Compliance
  - Purple → Accessibility

Storage & Versioning

- Store one‑pager visuals in `/assets/onepager/finance/`.
- Tag releases with quarter (e.g., `Q2-2026-onepager-visual`).
- Document updates in repo wiki.
