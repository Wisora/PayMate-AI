# PayMate AI – Governance Visual Guide

Purpose
Provide contributors with clear instructions for updating or recreating the governance cycle diagram.  
Ensures visuals remain consistent, accessible, and investor‑ready.

Tools & Platforms

- **Figma** – for collaborative design and version control
- **draw.io (diagrams.net)** – for quick diagram creation and repo‑friendly exports
- **VS Code Markdown Preview** – for embedding visuals directly in documentation

Design Standards

- **Color Coding:**
  - Governance → Blue
  - Investor → Green
  - Compliance → Orange
  - Security → Red
  - Quality → Purple
  - Accessibility → Teal
  - Audit → Orange/Red blend
  - Risk → Red/Orange blend
  - Roadmap → Green
  - Transparency → Teal
  - Contributor → Purple
  - Verification → Teal
  - Sync → Double‑headed arrows between Governance ↔ Investor

- **Shapes:**
  - Cycles → Circles
  - Layers → Rectangles
  - Master Index → Larger circle at bottom

- **Arrows:**
  - Use directional arrows to show flow
  - Double‑headed arrows for sync relationships

Accessibility Guidelines

- Provide **alt text** for every diagram:  
  _“Infographic showing interconnected governance cycles with arrows linking domains to the master index.”_
- Ensure **color contrast** meets WCAG 2.1 AA standards.
- Add **multilingual captions** for investor packets.
- Confirm diagrams are screen‑reader compatible when embedded in Markdown.

Workflow for Updates

1. Open the diagram in Figma or draw.io.
2. Apply updates (new cycles, renamed domains, revised flows).
3. Export as `.png` or `.svg`.
4. Save in `/docs/images/` or `/assets/visuals/`.
5. Update reference in `docs/ai-finance-master-cycle-governance-visual.md`.
6. Commit changes with version tag (e.g., `master-cycle-governance-map-v1.1.png`).
7. Sync updates with `docs/ai-finance-master-cycle-governance-map.md` and `docs/ai-finance-master-cycle-master-index.md`.
