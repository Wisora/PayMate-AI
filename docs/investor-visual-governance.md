# PayMate AI – Investor Visual Governance

Purpose
Establish governance rules for managing investor visuals.  
Ensures consistency, accountability, and professional polish across all materials.

Roles & Responsibilities

- **Founder (Craig)** → Final approval of visuals, alignment with investor strategy
- **Design Contributors** → Create charts, infographics, icons, and layouts
- **Repo Maintainers** → Ensure visuals are stored correctly in `/assets/` directories
- **Compliance Lead** → Verify accuracy of compliance visuals (GDPR, SOC 2, ISO 27001)
- **Metrics Lead** → Validate KPI data before charts are generated

Approval Process

1. Contributor drafts visuals based on scaffolds.
2. Maintainer reviews for style + repo standards.
3. Compliance/Metrics leads validate accuracy.
4. Founder provides final approval.
5. Approved visuals are committed + tagged with release.

Versioning

- **Quarterly Updates** → Tag releases (e.g., `Q2-2026-visual-update`)
- **Major Changes** → New branch (`visual-refresh-[quarter]`) before merge
- **Minor Fixes** → Direct commits with clear messages (e.g., `fix: updated compliance pie chart`)

Governance Rules

- All visuals must follow style standards (`docs/investor-style-visual.md`).
- Assets must be stored in correct `/assets/[visual-type]/` subfolders.
- No visuals are published without compliance + metrics validation.
- Quarterly review required before investor calls or deck updates.

Audit & Review

- **Quarterly Audit** → Verify visuals against updated KPIs + compliance milestones
- **Annual Review** → Assess branding refinements + roadmap visuals
- **Contributor Checklist** → Follow `docs/investor-visual-update-checklist.md`
