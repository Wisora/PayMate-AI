# PayMate AI – Investor Follow‑Up Checklist

Purpose
A reusable checklist for investor follow‑ups.  
Ensures every communication includes the right materials, links, and next steps.

Step 1: Thank You

- Send personalized thank‑you email (use `docs/investor-email-template.md`)
- Mention key highlights from the meeting/demo

Step 2: Core Materials

- Attach or link:
  - Investor Deck → `docs/investor-deck.md`
  - One‑Pager → `docs/investor-onepager.md`
  - Handout → `docs/investor-handout.md`
  - Summary Slide → `docs/investor-summary-slide.md`

Step 3: Compliance & Trust

- Include compliance summary → `docs/investor-compliance-summary.md`
- Mention roadmap to SOC 2 / ISO 27001

Step 4: Metrics & Dashboard

- Share metrics overview → `docs/investor-metrics.md`
- Share dashboard scaffold → `docs/investor-dashboard.md`

Step 5: Quick References

- FAQ → `docs/investor-faq.md`
- Talking Points → `docs/investor-talking-points.md`

Step 6: Demo & Scripts

- Offer live demo (guided by `docs/investor-demo-script.md`)
- Use briefing + closing scripts for consistency:
  - `docs/investor-briefing.md`
  - `docs/investor-closing-script.md`

Step 7: Package Index

- Link master index → `docs/investor-package.md`
- Mention checklist itself for transparency

Step 8: Next Steps

- Suggest scheduling follow‑up call/demo
- Offer deeper dive into roadmap or compliance
- Confirm preferred communication channel (email, call, deck review)

Usage Notes

- Always personalize with investor’s name and meeting context
- Keep follow‑up concise but link to full repo docs
- Update checklist quarterly alongside roadmap + metrics
