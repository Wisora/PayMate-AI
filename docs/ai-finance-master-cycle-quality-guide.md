# PayMate AI – Quality Guide for Cycles

Purpose
Provide a dedicated quality guide.  
Ensures audits, bug fixes, and contributor standards are consistently applied across quarterly, annual, and final stages.

Quality Standards

- [ ] Coding standards documented in `/docs/contributor/quality.md`
- [ ] Automated tests run across all commits (CI/CD pipeline)
- [ ] Bug fixes logged + tracked in `/logs/quality/issues/`
- [ ] Peer reviews completed for all PRs
- [ ] Accessibility checks integrated into QA workflow

Quarterly Quality Cycle

- [ ] Quarterly bug audit completed
- [ ] Contributor standards reviewed + updated
- [ ] Repo health metrics logged (coverage %, linting, build stability)
- [ ] Quarterly quality report archived in `/logs/quality/quarterly/`

Annual Quality Cycle

- [ ] Annual bug audit completed + archived
- [ ] Vendor audits confirmed + logged
- [ ] Annual repo health metrics compiled
- [ ] Annual quality report archived in `/logs/quality/annual/`

Final Quality Review

- [ ] Quality checklist confirmed in master final review
- [ ] Quality visuals included in investor packet
- [ ] Infographic summary prepared for investor materials
- [ ] Accessibility standards applied across QA reports

Continuous Quality Loop

- [ ] Quarterly quality logs synced with annual quality report
- [ ] Annual quality report synced with master annual report
- [ ] Final quality review outcomes fed into next year’s roadmap
- [ ] Lessons learned documented + integrated into contributor workflows
