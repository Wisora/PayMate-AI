# Investor Deck Style Guide

Color Palette

- Primary: Deep Blue (#1E3A8A) → trust, finance, professionalism
- Secondary: Emerald Green (#10B981) → growth, success, accessibility
- Accent: Gold (#F59E0B) → investor confidence, highlights
- Neutral: Light Gray (#F3F4F6) → background balance
- Text: Charcoal (#111827) → readability

Typography

- Headings: Sans‑serif, bold (e.g., Montserrat, Open Sans, or Segoe UI)
- Body Text: Clean sans‑serif (e.g., Lato, Roboto, or Calibri)
- Emphasis: Use bold or color accents, avoid italics for accessibility
- Font Sizes:
  - Title slides: 36–44pt
  - Section headers: 28–32pt
  - Body text: 20–24pt
  - Captions/footnotes: 16–18pt

Layout

- Grid: 2‑column layout for most slides (text left, visuals right)
- Margins: Consistent padding (safe zones for text/images)
- Icons: Use simple line icons for clarity (finance, cloud, compliance)
- Diagrams: Keep ASCII diagrams in docs, convert to clean vector graphics for slides

Visual Elements

- Workflow Diagrams: Simplify repo ASCII diagrams into flowcharts with arrows and icons
- Roadmap: Timeline graphic (horizontal milestones: MVP → Beta → Production → Enterprise)
- Compliance: Data flow diagram (user → API → secure storage → audit logs → compliance)
- Scaling: Layered architecture diagram (frontend → backend → DB → CDN → compliance)

Image Style

- Use _flat illustrations_ or _minimalist icons_ (avoid stock photos unless contextual).
- Keep visuals consistent in color palette.
- Highlight key investor slides with _accent gold_ for emphasis.

Slide Flow (Visual Consistency)

1. Title Slide → Deep Blue background, white text, logo centered.
2. Problem/Solution → Split layout: text left, icon/graphic right.
3. Demo → Screenshots or diagrams with captions.
4. Roadmap → Timeline graphic with green milestones.
5. Compliance/Scaling → Flow diagrams with blue/green accents.
6. Market/Business Model → Charts with gold highlights.
7. Team/Ask → Clean headshots/icons, minimal text.
8. Closing → Deep Blue background, logo, contact info.
