# PayMate AI – Governance Dashboard Release Checklist

Purpose
Provide a structured pre‑launch checklist for governance dashboard releases.  
Ensures accessibility, performance, data accuracy, and investor packet alignment before go‑live.

Pre‑Release Validation

Accessibility

- [ ] WCAG 2.1 AA compliance confirmed.
- [ ] Screen reader compatibility tested (NVDA, VoiceOver).
- [ ] Keyboard navigation verified.
- [ ] Accessibility checklist completed (`/docs/investor-governance-audit-evidence-dashboard-accessibility-checklist.md`).

Performance

- [ ] Lighthouse performance score ≥ 90.
- [ ] Load time ≤ 3 seconds on broadband.
- [ ] Responsive layout verified on desktop, tablet, mobile.

Data Accuracy

- [ ] KPI values cross‑checked against metrics file.
- [ ] Evidence snapshots validated against `/evidence/` directory.
- [ ] Dashboard sync timeliness confirmed (≤ 7 days after quarter close).

Investor Packet Alignment

- [ ] Dashboard visuals exported to investor packet.
- [ ] Quarterly summary integrated (`/docs/investor-governance-audit-evidence-summary.md`).
- [ ] Roadmap and maturity model progression noted.
- [ ] Investor Relations Lead review completed.

Sign‑Off Workflow

1. **Governance Lead** – KPI accuracy validated.
2. **Compliance Officer** – Accessibility compliance confirmed.
3. **Investor Relations Lead** – Packet alignment approved.
4. **Finance Lead** – Financial transparency confirmed.
