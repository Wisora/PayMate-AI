# PayMate AI – Investor Metrics Visual Scaffold

Purpose
This file provides a scaffold for converting PayMate AI’s key metrics into charts and infographics.  
It complements `docs/investor-metrics.md` (text KPIs) by offering visual representations for the deck and dashboard.

Visual Types

- Line Chart → User growth over time (monthly active users, subscriptions added)
- Bar Chart → Revenue breakdown (freemium vs paid tiers, B2B integrations)
- Pie Chart → Compliance coverage (GDPR, CCPA, POPIA, SOC 2 roadmap)
- Timeline Graphic → Roadmap milestones (MVP → Beta → Production → Enterprise)
- Gauge/Donut Chart → Fraud detection accuracy %

Data Sources

- Metrics file → `docs/investor-metrics.md`
- Dashboard scaffold → `docs/investor-dashboard.md`
- Roadmap milestones → `docs/roadmap.md`
- Compliance summary → `docs/investor-compliance-summary.md`

Storage & Integration

- Save visuals in `/assets/metrics-visuals/`
- Formats: SVG (scalable for deck), PNG (quick handouts)
- Embed into:
  - Investor Deck (`docs/investor-deck-slides.md`)
  - Investor Dashboard (`docs/investor-dashboard.md`)
  - Investor Package (`docs/investor-package.md`)
