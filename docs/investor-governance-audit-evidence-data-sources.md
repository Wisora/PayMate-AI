# PayMate AI – Investor Governance Audit Evidence Data Sources

Purpose
Map each governance audit evidence metric to its raw data source.  
Ensures full traceability from KPI → evidence → system/tool/workflow.

Compliance Data Sources

- **Policy Currency Rate**  
  Source: Governance calendar reminders (Outlook/Google Calendar) → Policy review logs (E‑001)
- **Audit Completion Rate**  
  Source: External compliance audit reports (PDF) → Compliance folder (E‑002)

Accessibility Data Sources

- **WCAG Compliance Rate**  
  Source: Accessibility audit tools (axe, Lighthouse) → Reports (E‑002)
- **Alt‑Text Coverage**  
  Source: Contributor submissions in GitHub PRs → Accessibility checklists (E‑003)

Security Data Sources

- **Patch SLA Compliance**  
  Source: CI/CD pipeline logs (GitHub Actions, Azure DevOps) → Deployment logs (E‑004)
- **Vulnerability Scan Coverage**  
  Source: Security scanners (OWASP ZAP, Snyk) → Scan reports (E‑005)
- **Risk Register Update Rate**  
  Source: Governance risk log (Jira/Notion) → Risk register entries (E‑006)

Verification Data Sources

- **Verification Completion Rate**  
  Source: Governance calendar reminders (Outlook/Google Calendar) → Reminder logs (E‑007)
- **Contributor Accountability Rate**  
  Source: Contributor checklist sign‑offs (GitHub PR templates) → Sign‑off records (E‑008)

Transparency Data Sources

- **Dashboard Sync Timeliness**  
  Source: Finance dashboards (Power BI, Tableau) → Dashboard logs (E‑009)
- **Archive Completeness Rate**  
  Source: Archive index audits (SharePoint/OneDrive) → Archive folder (E‑010)
- **Packet Alignment Rate**  
  Source: Investor packet drafts (Google Docs/Markdown) → Investor packets (E‑011)

Usage Notes

- Data sources updated quarterly alongside metrics file.
- Each KPI traceable to raw system/tool output.
- Evidence register cross‑links IDs to source systems.
- Ensures audit trail integrity for investors and regulators.
