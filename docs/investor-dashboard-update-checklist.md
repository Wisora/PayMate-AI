# PayMate AI – Investor Dashboard Update Checklist

Purpose
Provide a step‑by‑step checklist for contributors to update the investor dashboard each quarter.  
Ensures text and visual dashboards remain synchronized, accurate, and investor‑ready.

Step 1 – Roadmap Update

- [ ] Update `/docs/images/roadmap-diagram.png` with latest milestones
- [ ] Refresh `/docs/images/roadmap-legend.png` if new icons/colors added
- [ ] Confirm `/docs/ai-finance-roadmap-style-guide.md` is aligned

Step 2 – Investor Packet

- [ ] Update `/docs/investor-packet.md` with new quarterly highlights
- [ ] Add top 3–5 achievements to `/docs/investor-highlights.md`
- [ ] Archive previous packet in `/docs/investor-packets/archive/`
- [ ] Update `/docs/investor-packets/archive-index.md`

Step 3 – Investor Presentation

- [ ] Refresh `/docs/investor-presentation-outline.md` with current cycle
- [ ] Apply design standards from `/docs/investor-presentation-style-guide.md`
- [ ] Save new deck in `/docs/investor-presentations/`
- [ ] Archive older deck in `/docs/investor-presentations/archive/`
- [ ] Update `/docs/investor-presentations/archive-index.md`

Step 4 – Verification & Lessons

- [ ] Record quarterly outcomes in `/docs/quarterly-verification.md`
- [ ] Update `/docs/ai-finance-lessons-learned.md` with successes/challenges
- [ ] Link updates in `/docs/ai-finance-final-review.md`

Step 5 – Dashboard (Text)

- [ ] Update `/docs/investor-dashboard.md` with current cycle status
- [ ] Log past state in `/docs/investor-dashboard-history.md`
- [ ] Sync references in `/docs/investor-master-index.md`

Step 6 – Dashboard (Visual)

- [ ] Generate new infographic per `/docs/investor-dashboard-visual.md`
- [ ] Save as `/docs/images/dashboard/investor-dashboard-[year]-Q[quarter].png`
- [ ] Archive older infographic in `/docs/images/dashboard/archive/`
- [ ] Update `/docs/images/dashboard/archive-index.md`
- [ ] Sync unified view in `/docs/investor-dashboard-master.md`

Step 7 – Final Review

- [ ] Ensure accessibility compliance (contrast, alt‑text, labels)
- [ ] Verify all links are current and functional
- [ ] Collect sign‑offs from Investor Relations, Roadmap Owner, Governance, Finance
