# PayMate AI – Investor One‑Pager Visual Scaffold

Purpose
Provide a visual framework for the one‑page investor overview handout.  
Ensures concise, impactful visuals aligned with deck, handout, and summary slide.

Layout Overview

- **Header** → Logo + tagline (“Accessible Finance for the Subscription Economy”)
- **Section 1: Problem & Solution**
  - Infographic: Subscription chaos vs PayMate AI clarity
  - Icons: bills, alerts, dashboard snapshot
- **Section 2: Roadmap Timeline**
  - Horizontal timeline graphic (MVP → Beta → Production → Enterprise)
- **Section 3: Metrics Snapshot**
  - Line chart: user growth
  - Bar chart: revenue streams (freemium vs paid tiers)
- **Section 4: Compliance Status**
  - Pie chart: current vs planned certifications
- **Footer** → Quick facts strip (users, compliance, funding ask)

Visual Elements

- **Problem/Solution Infographic** → Side‑by‑side icons + captions
- **Roadmap Timeline** → Milestones with dates + icons
- **Metrics Charts** → Growth + revenue breakdown
- **Compliance Pie Chart** → GDPR, CCPA, POPIA, SOC 2 roadmap
- **Quick Facts Strip** → Infographic numbers (e.g., “Q2 2026 MVP”, “GDPR/CCPA compliant”, “Funding Ask: Infrastructure + Compliance”)

Style Standards

- Colors → From `docs/investor-style-visual.md` (deep blue, emerald green, bright orange, light gray)
- Typography → Deck fonts (Inter / Open Sans)
- Icons → Flat, minimal SVG (finance, compliance, accessibility)
- Layout → Single‑page, balanced whitespace, clear hierarchy

Asset Storage

- Directory: `/assets/onepager-visual/`
- Subfolders:
  - `/problem-solution/` → Infographics
  - `/roadmap/` → Timeline graphics
  - `/metrics/` → Charts
  - `/compliance/` → Pie charts
  - `/quickfacts/` → Fact strip visuals

Integration

- Embed visuals into:
  - Investor One‑Pager (`docs/investor-onepager.md`)
  - Investor Deck (`docs/investor-deck-slides.md`)
  - Investor Package (`docs/investor-package.md`)
