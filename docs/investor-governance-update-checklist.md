# PayMate AI – Investor Governance Update Checklist

Purpose
Provide a step‑by‑step checklist for contributors to update governance materials each quarter.  
Ensures compliance, security, accessibility, and verification outcomes are consistently documented.

Step 1 – Compliance

- [ ] Review ISO 27001 controls and update `/docs/compliance.md`
- [ ] Confirm GDPR data handling policies are current
- [ ] Check SOC 2 audit status and document remediation tasks
- [ ] Record updates in `/docs/investor-governance-dashboard.md`

Step 2 – Security

- [ ] Conduct quarterly vulnerability scan
- [ ] Document patch rollout in CI/CD pipeline
- [ ] Verify no critical findings remain open
- [ ] Log outcomes in `/docs/quarterly-verification.md`

Step 3 – Accessibility

- [ ] Ensure roadmap and governance visuals meet WCAG 2.1 AA standards
- [ ] Add alt‑text for all new images in `/docs/images/governance/`
- [ ] Confirm presentation decks meet accessibility guidelines
- [ ] Document compliance in `/docs/ai-finance-lessons-learned.md`

Step 4 – Governance Dashboard

- [ ] Update `/docs/investor-governance-dashboard.md` with current cycle status
- [ ] Log past state in `/docs/investor-governance-dashboard-history.md`
- [ ] Generate new infographic per `/docs/investor-governance-style-guide.md`
- [ ] Save as `/docs/images/governance/governance-report-[year]-Q[quarter].png`
- [ ] Archive older visuals in `/docs/images/governance/archive/`
- [ ] Update `/docs/investor-governance-visual-archive-index.md`
- [ ] Sync unified view in `/docs/investor-governance-dashboard-master.md`

Step 5 – Governance History

- [ ] Update `/docs/investor-governance-history.md` with quarterly outcomes
- [ ] Record lessons learned in `/docs/ai-finance-lessons-learned.md`
- [ ] Link updates in `/docs/ai-finance-final-review.md`

Step 6 – Final Review

- [ ] Ensure accessibility compliance (contrast, alt‑text, labels)
- [ ] Verify all governance links are current and functional
- [ ] Collect sign‑offs from Governance Lead, Compliance Officer, Investor Relations, Finance
