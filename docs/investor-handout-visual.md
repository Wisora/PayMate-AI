# PayMate AI – Investor Handout Visual Scaffold

Purpose
Provide a visual framework for the 2‑page investor handout.  
Ensures clarity, impact, and consistency with deck, dashboard, and package visuals.

Page 1 – Overview

- **Header** → Logo + tagline (“Accessible Finance for the Subscription Economy”)
- **Infographic** → Problem + Solution side‑by‑side graphic
- **Snapshot Graphic** → Subscription tracking + fraud alerts icons
- **Quick Facts Box** → Key numbers (users, roadmap milestones, compliance status)

Page 2 – Roadmap & Metrics

- **Roadmap Timeline Graphic** → MVP → Beta → Production → Enterprise
- **Metrics Chart** → Line chart of user growth + bar chart of revenue streams
- **Compliance Pie Chart** → Current vs planned certifications
- **Closing Visual** → Call‑to‑action banner (“Investor‑Ready. Contributor‑Friendly. Enterprise‑Polished.”)

- Typography → Deck fonts (Inter / Open Sans)
- Icons → Flat, minimal SVG (finance, accessibility, compliance)
- Layout → Two‑column design, balanced whitespace, consistent margins

Asset Storage

- Subfolders:

  - `/roadmap/` → Timeline visuals
  - `/metrics/` → Charts + compliance graphics

Integration
