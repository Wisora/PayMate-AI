# Contributor Overview – PayMate AI

Purpose
Provide contributors with a clear overview of onboarding, style standards, and workflow expectations.  
This README ensures contributors can quickly align with governance cadence and evidence logging.

Contributor Suite

Core Files

- **[CONTRIBUTING.md](CONTRIBUTING.md)** → Step‑by‑step onboarding guide.
- **[STYLE-GUIDE.md](STYLE-GUIDE.md)** → Standards for code, documentation, and visuals.
- **[CONTRIBUTOR-CALENDAR.md](CONTRIBUTOR-CALENDAR.md)** → Cadence of contributor updates, onboarding refreshes, and workflow reviews.

Linked Governance

- **[COMMUNICATIONS-CALENDAR.md](COMMUNICATIONS-CALENDAR.md)** → Contributor communications cadence.
- **[QUALITY-CALENDAR.md](QUALITY-CALENDAR.md)** → Contributor quality reviews.
- **[ACCESSIBILITY-CALENDAR.md](ACCESSIBILITY-CALENDAR.md)** → Contributor accessibility audits.
- **[MULTILINGUAL-CALENDAR.md](MULTILINGUAL-CALENDAR.md)** → Contributor localization cycles.

Contributor Expectations

1. **Onboarding**
   - Follow CONTRIBUTING.md for setup and workflow alignment.
   - Review STYLE-GUIDE.md for standards.

2. **Cadence**
   - Quarterly contributor updates logged in CONTRIBUTOR-CALENDAR.md.
   - Annual onboarding refresh ensures standards remain current.

3. **Evidence Logging**
   - Contributions linked to registers (e.g., ROADMAP-REGISTER.md, RISK-REGISTER.md).
   - Accessibility and multilingual contributions logged in respective registers.

Workflow Integration

- Contributors align with calendars for cadence.
- Evidence logged in registers for traceability.
- Governance binder consolidates contributor evidence for board review.

Usage

- **New Contributors** → Start with CONTRIBUTING.md and STYLE-GUIDE.md.
- **Active Contributors** → Follow calendars for cadence and log evidence in registers.
- **Governance Leads** → Ensure contributor updates integrated into master files.

Review Cadence

- **Quarterly** → Contributor calendar updated with onboarding and workflow evidence.
- **Annual** → Consolidated contributor evidence presented in board deck.
