Change Governance Principles

1. **Identification**
   - Changes logged in CHANGE-REGISTER.md.
   - Linked to roadmap and risk domains for traceability.

2. **Cadence**
   - Quarterly change reviews tracked in CHANGE-CALENDAR.md.
   - Annual consolidated change governance presented in board deck.

3. **Evidence Logging**
   - Change approvals and governance actions documented in registers.
   - Integrated into governance binder for board confidence.

4. **Transparency**
   - Change evidence consolidated annually.
   - Investor disclosures aligned with change cadence.

Workflow Integration

- Changes proposed → logged in register.
- Reviews and approvals → tracked in calendar.
- Risks and mitigations → linked to change governance.
- Evidence consolidated → governance binder and board deck.

Usage

- **Contributors** → Log changes and follow approval cadence.
- **Governance Leads** → Ensure change evidence logged and escalated.
- **Investors** → Review change suite for confidence in governance maturity.

Review Cadence

- **Quarterly** → Change calendar updated with reviews and evidence.
- **Annual** → Consolidated change governance presented in board deck.
