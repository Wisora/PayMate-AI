Purpose
Provide contributors, governance leads, and investors with a clear overview of continuous improvement governance.  
This README highlights lessons learned, calendars, and evidence, ensuring transparency and board‑readiness.

Continuous Improvement Principles

1. **Learning Cycles**
   - Lessons logged in LESSONS-REGISTER.md.
   - Retrospectives tracked in LESSONS-CALENDAR.md.

2. **Traceability**
   - Lessons linked to quality, risk, roadmap, and investor domains.
   - Consolidated annually in board deck.

3. **Transparency**
   - Lessons evidence consolidated annually in governance binder.
   - Investor disclosures aligned with improvement cadence.

4. **Actionability**
   - Lessons converted into roadmap updates, risk mitigations, and quality improvements.
   - Continuous improvement cycles documented quarterly.

Workflow Integration

- Lessons identified → logged in register.
- Retrospectives → tracked in calendar.
- Linked evidence → quality, risk, roadmap, and investor domains.
- Consolidated evidence → governance binder and board deck.

Usage

- **Contributors** → Participate in retrospectives and log lessons.
- **Governance Leads** → Ensure lessons evidence logged and escalated.
- **Investors** → Review lessons suite for confidence in governance maturity.

Review Cadence

- **Quarterly** → Lessons calendar updated with retrospectives and evidence.
- **Annual** → Consolidated lessons governance presented in board deck.
