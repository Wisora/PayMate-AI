# Style Guide – PayMate AI

Purpose
Provide a consistent visual and design framework for documentation, diagrams, and investor decks.  
Ensures accessibility, professionalism, and investor‑ready polish.

Typography

- **Headings** → Sans‑serif, bold, accessible (minimum 18pt).
- **Body Text** → Sans‑serif, regular weight, minimum 16pt.
- **Code Blocks** → Monospace font, consistent indentation.
- **Accessibility** → All text must meet WCAG 2.1 AA contrast standards.

Color Palette

- **Primary** → Deep Blue (#1E3A8A) – trust, stability.
- **Secondary** → Emerald Green (#10B981) – growth, compliance.
- **Accent** → Gold (#F59E0B) – investor confidence.
- **Neutral** → Gray (#6B7280) – balance, readability.
- **Accessibility** → Avoid red/green combinations; ensure high contrast.

Layout & Visuals

- **Decks** → Clean, minimal slides with max 6 bullet points.
- **Diagrams** → Use repo maps and flowcharts with labeled nodes.
- **Tables** → Clear headers, alternating row shading for readability.
- **Images** → Alt text required; multilingual captions where relevant.

Icons & Branding

- **Logo Placement** → Top‑right corner of decks and visuals.
- **Icons** → Use simple, flat icons aligned with accessibility standards.
- **Brand Consistency** → All visuals must align with PayMate AI’s investor‑ready identity.

Multilingual Standards

- Decks localized in **English, Spanish, French**.
- Repo diagrams include multilingual labels where applicable.
- CI pipeline validates translation completeness before merge.

Accessibility Standards

- Minimum font size: 16pt.
- High‑contrast palette enforced.
- Alt text for all images and diagrams.
- Screen reader compatibility for documentation.

Review Cadence

- **Quarterly** → Style guide reviewed alongside governance binder.
- **Annual** → Consolidated updates integrated into investor deck.
